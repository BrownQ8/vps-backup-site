VPS Backup · Privacy policy

Privacy policy

This policy describes the personal VPS Backup tool operated by brownq8.

Data accessed and purpose

The tool processes selected application files, configuration data, and database exports to create encrypted recovery backups. Through rclone it accesses Google Drive repository files and metadata to upload, list, read, restore, and remove backup data according to the owner’s retention settings. Google account authorization is used solely to enable these operations.

Storage and security

Restic encrypts backup content before upload to Google Drive. OAuth credentials and the repository password are stored on the operator’s server, not in this website or its public source repository. Local staging copies may contain unencrypted database exports and are restricted on the server. No system can guarantee absolute security.

Sharing and use

The operator does not sell Google user data, use it for advertising, or use it to train AI models. Backup data is transmitted to Google Drive for storage. The operator does not intentionally share backup content with other parties except as required by law. Google processes service data under its own policies.

Retention and deletion

Backup snapshots are retained according to the owner’s configured policy. Removing old snapshots and pruning reclaims repository data that is no longer referenced. Revoking access stops future authorized operations but does not automatically delete existing backups. The owner can remove the repository through Google Drive when no longer needed.

Control and revocation

The owner can revoke the app’s access through Google Account third-party connections. Reauthorization is needed to resume backups afterward.

This website

This static site contains no login form, advertising, analytics scripts, or application cookies. GitHub Pages hosts the site and may process request information such as IP addresses under GitHub’s privacy statement.

Contact

For policy questions, contact the operator through the brownq8 GitHub profile. Do not post credentials, tokens, backup contents, or private account details publicly.
