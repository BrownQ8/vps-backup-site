VPS Backup

A private, owner-operated tool for backing up self-hosted applications to Google Drive.

Purpose

VPS Backup uses Restic to encrypt backup snapshots and rclone to transfer repository data to the owner’s Google Drive account. It is intended for the owner’s personal use, not offered as a public backup service.

Google Drive access

Google authorization allows the tool to store, list, read, and maintain its backup repository, including removing expired backup data under the configured retention policy. Permissions shown on Google’s consent screen may allow broader Drive access; approve only if you trust the operator.

This public website is informational only. It does not provide access to backups, accept credentials, or initiate Google authorization.

Read the privacy policy for data handling and revocation details.
